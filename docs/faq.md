# 常见问题

以下是使用过程中可能遇到的常见问题及解答。

## 安装问题

### Q1：安装过程中提示权限不足

**A1**：请以管理员身份运行安装程序：

- Windows：右键点击安装程序，选择「以管理员身份运行」
- macOS：打开终端，输入 `sudo installer -pkg product.pkg -target /`
- Linux：使用 `sudo` 命令安装，如 `sudo dpkg -i product.deb`

### Q2：安装后无法启动

**A2**：请检查以下几点：

1. 确认系统满足最低要求
2. 检查是否有足够的内存和存储空间
3. 查看系统日志，查找错误信息
4. 尝试重新安装产品

## 使用问题

### Q1：如何重置密码

**A1**：请按照以下步骤重置密码：

1. 打开登录页面
2. 点击「忘记密码」链接
3. 输入您的邮箱地址
4. 查看邮箱，点击密码重置链接
5. 输入新密码，点击「确认」按钮

### Q2：如何导出项目

**A2**：请按照以下步骤导出项目：

1. 打开项目详情页
2. 点击「导出」按钮
3. 选择导出格式（HTML/PDF/Markdown/JSON）
4. 点击「导出」按钮
5. 等待导出完成，保存文件到本地

### Q3：如何添加项目成员

**A3**：请按照以下步骤添加项目成员：

1. 打开项目详情页
2. 点击「成员管理」选项卡
3. 点击「添加成员」按钮
4. 输入成员邮箱和姓名
5. 选择成员角色（admin/member/guest）
6. 点击「添加」按钮

## 技术问题

### Q1：项目无法加载

**A1**：请检查以下几点：

1. 确认网络连接正常
2. 检查项目文件是否损坏
3. 尝试清除浏览器缓存
4. 尝试使用其他浏览器

### Q2：文件无法保存

**A2**：请检查以下几点：

1. 确认有足够的存储空间
2. 检查文件是否被其他程序占用
3. 尝试重新登录产品
4. 查看系统日志，查找错误信息
