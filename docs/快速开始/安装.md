# 安装

本产品支持多种安装方式，您可以根据自己的使用场景选择合适的方法。

## 前置要求

- 操作系统：Windows 10/11、macOS 10.15+ 或 Linux
- 内存：至少 4GB RAM
- 存储：至少 1GB 可用空间

## 方式一：直接下载安装包

### Windows

1. 访问产品官网下载页面
2. 下载 Windows 安装包（.exe 文件）
3. 双击安装包，按照向导完成安装
4. 安装完成后，从开始菜单启动产品

### macOS

1. 访问产品官网下载页面
2. 下载 macOS 安装包（.dmg 文件）
3. 打开 .dmg 文件，将产品图标拖拽到 Applications 文件夹
4. 从 Launchpad 或 Applications 文件夹启动产品

### Linux

1. 访问产品官网下载页面
2. 下载 Linux 安装包（.deb 或 .rpm 文件）
3. 使用包管理器安装：
   - Debian/Ubuntu：`sudo dpkg -i product.deb`
   - CentOS/RHEL：`sudo rpm -ivh product.rpm`

## 方式二：使用包管理器

### 命令行安装（推荐）

```bash
# 使用 npm 安装
npm install -g product-name

# 或者使用 yarn 安装
yarn global add product-name
```

## 验证安装

安装完成后，打开终端（或命令提示符），输入以下命令验证安装：

```bash
product --version
```

如果显示版本号，则说明安装成功。
