# 首次使用

恭喜您成功安装产品！现在让我们开始首次使用，完成基本配置。

## 启动产品

1. 打开产品应用程序
2. 如果是首次启动，会显示欢迎向导
3. 按照向导完成基本设置

## 配置账号

### 注册新账号

1. 在登录页面点击「注册」
2. 填写邮箱、用户名和密码
3. 点击「注册」按钮
4. 查看邮箱并点击验证链接
5. 验证成功后，使用新账号登录

### 使用已有账号登录

1. 在登录页面输入邮箱和密码
2. 点击「登录」按钮
3. 如果启用了二步验证，输入验证码
4. 登录成功后，进入产品主界面

## 基本设置

### 语言设置

1. 点击右上角头像 -> 「设置」
2. 在「语言」选项中选择您喜欢的语言
3. 点击「保存」按钮，界面会自动刷新

### 主题设置

1. 点击右上角头像 -> 「设置」
2. 在「主题」选项中选择「浅色」或「深色」
3. 点击「保存」按钮，界面会自动切换主题

## 创建第一个项目

1. 在主界面点击「新建项目」
2. 填写项目名称和描述
3. 选择项目类型
4. 点击「创建」按钮
5. 项目创建成功后，进入项目详情页

## 导入现有项目

1. 在主界面点击「导入项目」
2. 选择项目文件或输入项目地址
3. 点击「导入」按钮
4. 等待导入完成，进入项目详情页

## 下一步

完成首次使用配置后，您可以：

- 查看「功能说明」模块了解产品的各项功能
- 查看「常见问题」模块解答使用过程中可能遇到的问题
